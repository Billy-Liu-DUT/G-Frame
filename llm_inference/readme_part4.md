# v1 Retained Component: Model Serving

This directory is retained from G-Frame v1 as a reference for exposing a
model through an OpenAI-compatible endpoint. In G-Frame v2, it is an optional
serving-side component adjacent to the workflow stages that make model calls.

See the repository root [`readme.md`](../readme.md) for the coarse
manuscript-flow-to-module map and the v2 execution surface. Model locations,
devices, endpoint settings, and service lifecycle remain operator-managed.

This note preserves the v1 component boundary; it does not define a required
v2 deployment arrangement.
