# v1 Retained Component: Chat Interface

This directory is retained from G-Frame v1 as an optional local interface for
manual interaction with an OpenAI-compatible model endpoint. It is separate
from the automated G-Frame v2 workflow.

For the coarse correspondence between the manuscript flow and v2 engineering
modules, see the repository root [`readme.md`](../readme.md). Endpoint,
credential, model, and interface settings are supplied by the operator.

This note records v1-to-v2 continuity only; the v2 source and configuration
files define workflow behavior.
