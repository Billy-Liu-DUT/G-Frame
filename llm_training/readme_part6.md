# v1 Retained Component: Training

This directory continues the G-Frame v1 training area. At a coarse level in
G-Frame v2, it owns the manuscript flow's pretraining and full-parameter
supervised fine-tuning entrypoints, while orchestration and artifact handoff
are coordinated by the v2 workflow modules.

The repository root [`readme.md`](../readme.md) is the authoritative map of
the manuscript flow to engineering modules. Model paths, stage configuration,
inputs, validation inputs, and output locations are supplied by the operator.

This retained note describes the component boundary rather than a training
recipe or an operational outcome.
