# v1 Retained Component: Graph Retrieval

This directory is retained from G-Frame v1 as an optional graph-backed
retrieval and interface component. It remains outside the required execution
path of the default G-Frame v2 workflow.

For the coarse correspondence between the manuscript flow and v2 engineering
modules, see the repository root [`readme.md`](../readme.md). Endpoints,
models, source documents, graph storage, and output locations are
operator-supplied.

This note records v1-to-v2 continuity only. The root documentation and v2
source modules define the active workflow contract.
